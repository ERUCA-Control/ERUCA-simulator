# ERUCA 비행 시뮬레이터

발사 조건과 기체·모터·낙하산 조건을 입력해 예상 비행 궤적과 낙하산 사출 지점을 계산하는 로컬 Python 프로그램입니다. RocketPy 1.13.0을 사용합니다.

이 버전은 **비행 예측용 프로토타입**입니다. 실제 기체의 검증된 제원이 제공되지 않아 기본값과 `example.json`의 기체·추력 곡선은 임의 예시입니다. ERUCA의 실제 로켓 성능을 나타내지 않습니다.

## 실행 준비

- Python **3.10 이상**이 필요합니다. Python 3.11 또는 3.12와 Tkinter가 포함된 공식 Python 설치본을 권장합니다.
- 패키지를 처음 설치할 때 인터넷이 필요합니다. 설치가 끝난 뒤의 비행 계산은 로컬에서 실행하며 기상 서버·지도·외부 API를 조회하지 않습니다.
- 그래픽카드나 CUDA 설치는 필요하지 않습니다. 수치 계산은 CPU를 사용합니다. 제시한 Ryzen 5 9600X / RAM 64 GB / RTX 5060 환경에서 사용할 수 있는 구성이나 해당 PC에서 처리 시간은 측정하지 않았습니다.
- 압축 파일을 받았다면 **전체 폴더를 먼저 압축 해제**합니다. 폴더 안 파일들을 함께 보관합니다.

## Windows에서 실행

1. [Python 공식 Windows 다운로드](https://www.python.org/downloads/windows/)에서 Python을 설치합니다. Python launcher와 Tcl/Tk 지원을 포함합니다.
2. `run_windows.bat`를 실행합니다.
3. 처음 실행하면 이 폴더 안에 `.venv`를 만들고 필요한 패키지를 설치한 뒤 창을 엽니다.

설치된 패키지를 확인한 이후 실행에서는 설치를 반복하지 않습니다. 오류가 나면 콘솔에 원인이 표시됩니다. Windows Python 설치본에 Tkinter가 빠졌다면 설치 프로그램의 Modify 메뉴에서 Tcl/Tk를 추가합니다.

수동 실행은 이 폴더에서 다음과 같이 할 수 있습니다.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

가상환경을 활성화하지 않고 위 명령처럼 그 안의 Python을 직접 실행해도 됩니다.

## macOS에서 실행

[Python 공식 macOS 다운로드](https://www.python.org/downloads/macos/)에서 Tkinter가 포함된 Python을 설치한 다음 `run_macos.command`를 실행합니다. 실행 권한이 유지되지 않았다면 이 폴더의 터미널에서 다음 명령으로 실행합니다.

```bash
bash run_macos.command
```

수동 설치·실행:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Linux에서도 같은 수동 명령을 사용할 수 있습니다. 배포판에 따라 Python venv 및 Tkinter 패키지가 별도로 필요합니다. 예를 들어 Debian/Ubuntu는 `python3-venv`, `python3-tk`를 사용합니다.

## 사용 흐름

1. 프로그램을 열면 예시 설정으로 첫 비행을 계산합니다. 먼저 결과의 종류와 단위를 확인합니다.
2. **비행 설정** 탭에서 모터를 제외한 기체 질량, 추력 배율, 발사 고각·방위각, 바람, 낙하산 사출 조건·지연·Cd×면적, 계산 종료 시간을 수정합니다.
3. 발사점 위경도·표고, 레일 길이, 기체 길이·반지름·관성·무게중심, 모터 질량·추력 곡선 등은 **전체 제원 JSON** 탭에서 수정합니다. 편집 후 반드시 **JSON 내용을 설정에 적용**을 누릅니다. 적용하지 않은 JSON 편집은 다음 계산에 반영되지 않습니다.
4. **비행 계산**을 누릅니다. 입력을 바꾼 뒤에는 다시 계산해야 결과가 갱신됩니다.
5. 3D 궤적, 고도·속력 그래프, 수평 궤적을 확인합니다. 3D 그래프를 드래그해 시점을 회전할 수 있습니다. **재생/일시정지**, 배속, 시간 슬라이더로 계산된 비행을 살펴봅니다. 이벤트 표의 행을 클릭하면 해당 시각으로 이동합니다.
6. **제원 저장/열기**로 입력 JSON을 보관하거나 불러옵니다. **예제 초기화**는 입력을 기본 예시로 되돌리며, 결과를 갱신하려면 비행 계산을 누릅니다.
7. **결과 내보내기**로 계산 결과 JSON과 궤적·이벤트 CSV를 함께 저장합니다.

재생은 미리 계산한 궤적의 표시입니다. 재생 배속을 바꾸어도 물리 계산 결과는 달라지지 않습니다. 결과는 입력한 한 조건에 대한 예측이며 확률적 착지 범위를 의미하지 않습니다.

기본 예시는 모터 제외 기체 질량 4.0 kg, 모터 건조 질량 0.4 kg, 추진제 질량 0.3 kg으로 초기 총질량 4.7 kg입니다. 추력 곡선은 최대 300 N·1.8초 길이의 임의 합성 곡선입니다. 실제 ERUCA 기체나 인증된 모터의 제원이 아닙니다.

GUI 외에 명령줄에서도 계산할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe simulation.py --config example.json --output result.json
```

macOS/Linux:

```bash
.venv/bin/python simulation.py --config example.json --output result.json
```

`result.json`을 지정하면 같은 폴더에 다음 세 파일을 만듭니다. GUI 결과 내보내기도 같은 규칙입니다.

| 파일 | 내용 |
|---|---|
| `result.json` | 입력 제원 `config`, 요약 `summary`, 이벤트 `events`, 시계열 `samples` |
| `result.csv` | 시간별 위치·속도·가속도·기압·자세 등 모델 계산값 |
| `result_events.csv` | 발생한 이벤트의 시각·위치·종류 |

시계열의 기본 간격은 0.1초이며 이벤트의 실제 보고 시각을 추가로 포함합니다. 이 간격은 화면 재생·저장 간격이며 수치 적분의 최대 시간 간격이나 사출 조건 검사 주기와 다릅니다. 계산 종료 시간이 착지보다 먼저 오면 착지 좌표가 없으며, 마지막 표본을 착지점으로 해석하면 안 됩니다. JSON의 `summary.landed`, `summary.termination`에서도 종료 상태를 확인할 수 있습니다.

## 사출 조건과 좌표 해석

프로그램에서 선택하는 사출 조건은 **정해진 조건을 만족하면 발동하는 결정론적 시뮬레이션 규칙**입니다.

- **최고점:** 시뮬레이션에서 상승이 하강으로 전환되는 조건을 사용합니다.
- **하강 중 고도:** 먼저 지정 고도에 도달한 뒤 하강하면서 그 고도를 아래로 통과할 때의 조건입니다. 최고점이 설정 고도보다 낮으면 사출되지 않습니다.
- **발사 후 시간:** 점화로 정의한 시뮬레이션 시작 `t=0`부터 지정한 시간이 지날 때의 조건입니다. 실제 이륙 감지 후 경과 시간과 다릅니다.

조건은 설정한 주기로 검사하므로 수학적인 최고점·고도 통과 시각과 명령 시각 사이에 표본 주기 수준의 차이가 날 수 있습니다. 조건을 만족하지 않거나 지면에 먼저 도달하면 사출 이벤트가 없을 수 있습니다.

다음 세 지점은 서로 다릅니다.

| 지점 | 뜻 |
|---|---|
| 사출 명령 지점 | 설정한 사출 조건이 감지된 순간의 로켓 위치 |
| 낙하산 전개 지점 | 사출 명령 이후 설정된 지연이 지나 낙하산 항력이 비행 모델에 반영되는 위치 |
| 착지 지점 | 모델의 지면과 만나는 위치 |

전개 지연은 단순 지연 모델입니다. 실제 캐노피가 펼쳐지는 과정, 줄 전개, 사출 기구, 회수 장치의 역학을 해석해 완전 전개 지점을 검증하는 기능은 없습니다. 화면의 전개 지점도 이 지연 모델을 기준으로 해석합니다.

위치와 단위는 다음을 기준으로 합니다.

- **ENU:** 발사점을 기준으로 동쪽(East) `+x`, 북쪽(North) `+y`, 위쪽(Up) `+z`입니다. 거리 단위는 m입니다.
- **AGL 고도:** 발사 지점 지면을 기준으로 한 높이(m)입니다. 이 버전은 지면을 평평하게 처리하므로 실제 산·지형의 높이를 따라 계산한 지상고가 아닙니다.
- **발사 지점 표고:** 평균 해수면 기준 발사 지점 높이(m)입니다. AGL 고도와 구분합니다.
- **위도·경도:** 발사 지점에서 계산된 수평 변위를 구면 지구의 국소 근사로 변환합니다. 소규모 비행 영역을 위한 근사이며 지형·정밀 측지·장거리 항법 계산이 아닙니다.
- 속도는 m/s, 시간은 s, 질량은 kg, 추력은 N, 각도는 도(°)를 기준으로 입력합니다.

바람의 동쪽·북쪽 성분은 **공기가 이동하는 방향**입니다. 동쪽 성분이 양수이면 동쪽으로 부는 바람입니다. 기상 자료의 '바람이 불어오는 방향'과 혼동하지 않습니다.

## 모델의 범위

- RocketPy의 6자유도 비행 계산과 낙하산 하강 모델을 사용합니다.
- 표준 기압·온도와 입력한 **일정한 수평 바람** 조건으로 계산합니다. 고도별 바람, 돌풍, 실시간 기상 예보 다운로드는 포함하지 않습니다.
- 기체 길이·반지름을 바꾸면 정해진 비율의 노즈와 4개 사다리꼴 날개가 함께 바뀝니다. **노즈와 날개의 독립적인 형상 편집은 지원하지 않습니다.** 레일 버튼과 모터의 내부 치수·위치도 비례식으로 정해지며, 모터 건조 관성은 코드의 고정 예시값입니다. 제원 JSON으로 실제 기체 전체 형상을 자유롭게 정의하는 도구는 아닙니다.
- 기본 모터 입력은 예시 추력 곡선을 사용하는 집중정수 `GenericMotor` 모델입니다. 관성·질량 분포를 포함한 상세 모터 모델의 검증은 이루어지지 않았습니다.
- 기체 제원·질량·관성·항력·추력 곡선·낙하산 항력 계수와 면적·바람이 바뀌면 결과도 달라집니다. 입력을 실제 측정·제조사 자료로 교체해야 실제 기체와 비교할 수 있습니다.
- 최고점 부근이나 하강 중 역방향 유동·텀블링에서의 공력 모델은 검증되지 않았습니다. 낙하산 전개가 추력 비행 중 발생하는 조건도 검증 범위 밖입니다.
- 낙하산 항력이 반영된 이후의 기체 자세는 유효한 회수강하 자세 모델로 취급하지 않습니다. 화면에서 기체 방향선을 숨기고, 시계열의 `attitude_valid`를 `false`로 기록합니다. JSON/CSV에 남아 있는 자세·기울기 값은 이 플래그와 함께 해석해야 합니다.
- RocketPy의 지구 자전/코리올리 효과를 유지합니다. 따라서 수직·무풍 조건에서도 작은 수평 이동이 생길 수 있습니다.
- 센서의 진실값과 측정값을 구분하는 센서 시뮬레이션, MS5611/WT901의 오차·지연·진동·포화, 자세 융합, 탑재 알고리즘 검증은 이 버전의 범위 밖입니다.
- 지상국 통신, LoRa, 실제 ESP32 입출력, 릴레이 제어, 사출 장치 출력은 포함하지 않습니다.

따라서 이 결과는 **센서 기반 실제 탑재 사출 로직의 안전성 검증 결과가 아닙니다.** 예측 궤적과 정해진 사출 규칙을 살펴보는 출발점으로 사용합니다.

## 확인한 범위

엔진 동작 검사 8개와, 실제 Matplotlib 그림 생성·시간 이동·이벤트 선택 상태를 확인하는 뷰어 검사 3개를 통과했습니다. 수치 적분은 `RK45`를 사용합니다. 예시 조건에서 최대 적분 간격을 0.05초에서 0.025초로 줄인 비교 결과는 최고점 약 0.017 m, 착지 위치 약 0.004 m 차이였습니다. 이는 해당 예시의 수치 수렴 확인이며 실제 비행 예측 정확도를 의미하지 않습니다. macOS 샌드박스에서 네이티브 창 실행은 `RegisterApplication` 단계에서 중단되어 전체 GUI 창을 직접 확인하지 못했습니다. Windows 실행 스크립트의 실제 실행도 미확인입니다. macOS 실행 스크립트의 셸 문법은 확인했습니다.

## 검증 다시 실행

설치가 끝난 뒤 이 폴더에서 다음 명령으로 계산 및 창을 띄우지 않는 표시 로직 검사를 실행합니다.

```bash
python -m unittest discover -s tests -v
```

Windows 런처로 설치했다면 `python` 대신 `.venv\Scripts\python.exe`, macOS/Linux는 `.venv/bin/python`을 사용합니다. `example_result.json`과 `example_flight.png`는 가상 예제 기체의 계산 결과입니다.
